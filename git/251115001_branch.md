# Merge Conflict

Conflicts that occur during a merge

## Reproducing a Merge Conflict

- $ touch fizzbuzz.py
- $ git branch fizz
- $ git branch    # *main fizz
- $ vi fizzbuzz.py    # feat: Print fizz
- $ git switch fizz
- $ git branch    # main *fizz
- $ vi fizzbuzz.py    # feat: Print buzz
- $ git switch main
- $ git merge fizz    # merge conflict

## How to Solve

### Solve During a Merge

- $ git merge fizz    # merge conflict
- $ vi fizzbuzz.py    # resolve conflict (remove <<<<<, =====, >>>>>)
- $ git add fizzbuzz.py
- $ git commit

### Solve with Rebase (Case 1)

- $ touch fizzbuzz.py
- $ git branch fizz
- $ git branch    # *main fizz
- $ vi fizzbuzz.py    # feat: Print fizz
- $ git switch fizz
- $ git branch    # main *fizz
- $ cat fizzbuzz.py    # nothing (file created only on main)
- $ git rebase main
- $ cat fizzbuzz.py    # feat: Print fizz

### Solve with Rebase (Case 2)

- $ touch fizzbuzz.py
- $ git branch fizz
- $ git branch    # *main fizz
- $ vi fizzbuzz.py    # feat: Print fizz
- $ git switch fizz
- $ git branch    # main *fizz
- $ vi fizzbuzz.py    # feat: Print buzz
- $ git rebase main    # merge conflict
- $ vi fizzbuzz.py    # resolve conflict
- $ git add fizzbuzz.py
- $ git rebase --continue
