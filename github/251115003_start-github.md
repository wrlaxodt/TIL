# Co-work with git, github

## Issue

Tracks tasks, bugs, and questions in a GitHub project

- Used to manage work items, bugs, questions, and feedback
- Helps organize and communicate progress within the team
- Labels, assignees, and status updates are important for smooth workflow

## Issue template

Define different issue templates for features, bugs, and questions

- ## Description
- One-line summary of the feature
- Additional details (you may freely add images, videos, etc.)

- ## Tasks
- # - [ ] Item 1
- # - [ ] Item 2
- # - [ ] Item 3

- ## References
- # - [Link text](Link addr)

## Project

- Task management based on repository issues in GitHub
- Supports both Scrum board and table views
- Only team admins can manage project settings
- Can be automated to update through commits, pull requests, and more
